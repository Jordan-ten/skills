# skills

Personal Claude Code skills for the Tennaxia (traace) project, packaged as a plugin.

## Use

- Quick test: `claude --plugin-dir ~/code/skills`
- Install: `/plugin marketplace add ~/code/skills`, then `/plugin install traace-perso@jordan-skills`

## Add a skill

Create `skills/<name>/SKILL.md`. It is called `traace-perso:<name>`.
